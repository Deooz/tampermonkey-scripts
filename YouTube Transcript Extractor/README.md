# YouTube Transcript Extractor

![Version](https://img.shields.io/badge/version-2.1.0-blue.svg)
![License](https://img.shields.io/badge/license-MIT-green.svg)

Extrae la transcripción completa de un video de YouTube y la presenta en una ventana emergente (popup) flotante y editable.

![Ejemplo de cómo se ve el script](https://via.placeholder.com/600x300.png?text=Añadir+captura+de+pantalla+aquí)

## ✨ Características

-   **Popup Editable:** La transcripción aparece en una ventana que te permite editar el texto directamente.
-   **Contenido Completo:** Además de la transcripción, el script también extrae y añade la descripción del video.
-   **Fuente Automática:** Incluye un enlace a la fuente original del video (título y URL) al final del texto.
-   **Manejo de Capítulos:** Si el video tiene capítulos, el script los formatea como títulos (H2) para una mejor estructura.
-   **Seguro:** Utiliza `Trusted Types` para insertar el contenido en la página, previniendo ataques XSS.

## ⚙️ Instalación

1.  Asegúrate de tener instalada la extensión [Tampermonkey](https://www.tampermonkey.net/) en tu navegador.
2.  Haz clic en el siguiente enlace para instalar el script: **[Instalar Script](https://raw.githubusercontent.com/Deooz/tampermonkey-scripts/master/YouTube%20Transcript%20Extractor/YouTube%20Transcript%20Extractor.user.js)**.
